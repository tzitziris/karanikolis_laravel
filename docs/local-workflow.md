# Καθημερινή δουλειά: φωτογραφίες, προβολή στο κινητό, ανέβασμα

Όλες οι εντολές τρέχουν στο Terminal, μέσα στον φάκελο του project:

```bash
cd ~/cursor_ai/karanikolis_laravel
```

## Αλλαγή φωτογραφίας

1. Βάλε τη νέα φωτογραφία στο `resources/images/static/` με **ακριβώς το ίδιο όνομα και την ίδια
   κατάληξη** με την παλιά (π.χ. `ring-training.jpg`), πάνω από την παλιά. Αν αλλάζει η κατάληξη
   (π.χ. `.png`), πρέπει να αλλάξει και η γραμμή της στο `config/images.php`.
   Όριο: 8 MB και 5000px ανά πλευρά. Προτίμησε JPEG, γιατί ένα μεγάλο PNG ξεπερνά εύκολα τα 8 MB.
2. Φτιάξε τα webp και τη θολή προεπισκόπηση:

   ```bash
   php artisan images:build-static --force
   ```

3. Χτίσε το CSS/JS. Χρειάζεται επειδή η λίστα των φωτογραφιών μπαίνει μέσα στο JavaScript:

   ```bash
   npm run build
   ```

4. Δες το αποτέλεσμα στον υπολογιστή ή στο κινητό (παρακάτω).

**Μην** βάζεις φωτογραφίες στο `public/images/static/`. Εκεί γράφει μόνο η εντολή του βήματος 2,
και ό,τι βρίσκεται εκεί το βλέπει όλος ο κόσμος.

## Προβολή στο κινητό πριν το ανέβασμα

Το κινητό πρέπει να είναι στο **ίδιο Wi-Fi** με τον υπολογιστή.

1. Σταμάτησε όποιο `php artisan serve` τρέχει ήδη (Ctrl+C) και ξεκίνησέ το έτσι:

   ```bash
   php artisan serve --host=0.0.0.0 --port=8000
   ```

   Το `--host=0.0.0.0` το κάνει ορατό σε όλο το τοπικό δίκτυο. Χωρίς αυτό, το βλέπει μόνο ο
   υπολογιστής.

2. Βρες τη διεύθυνση του υπολογιστή στο δίκτυο:

   ```bash
   ipconfig getifaddr en0
   ```

3. Στο κινητό άνοιξε `http://ΑΥΤΗ-Η-ΔΙΕΥΘΥΝΣΗ:8000`, π.χ. `http://192.168.1.28:8000`. Με `http`,
   όχι `https`.

Αν δεν ανοίγει:
- Το macOS ίσως ρωτήσει αν επιτρέπει εισερχόμενες συνδέσεις στην PHP. Πάτα Allow.
- Η διεύθυνση του υπολογιστή μπορεί να αλλάξει από μέρα σε μέρα. Ξανατρέξε το βήμα 2.
- Πρέπει να τρέχει και η βάση (Docker Desktop ανοιχτό).

Το κινητό βλέπει ό,τι έχει χτιστεί με το `npm run build`. Μετά από κάθε αλλαγή, ξανάτρεξε το build
και κάνε ανανέωση στο κινητό.

Για τα animation: αν στο κινητό δεν κινείται τίποτα, έλεγξε τη «Μείωση κίνησης» (iPhone: Ρυθμίσεις →
Προσβασιμότητα → Κίνηση). Όταν είναι ανοιχτή, το σαιτ κλείνει σκόπιμα τα animation.

## Ανέβασμα στον server

1. Βεβαιώσου ότι τα tests περνούν:

   ```bash
   php artisan test
   ```

2. Φτιάξε το πακέτο:

   ```bash
   bash scripts/pack-deploy.sh
   ```

   Τρέχει μόνο του το `npm run build` και γράφει το `karanikolis-deploy.zip` **έναν φάκελο πάνω**
   από το project (`~/cursor_ai/karanikolis-deploy.zip`). Το `images:build-static` **δεν** το
   τρέχει, οπότε μετά από νέα φωτογραφία πρέπει να έχει γίνει πρώτα το βήμα 2 της αλλαγής
   φωτογραφίας.

3. Στο cPanel → File Manager → `karanikolis.twomymenu.com/` → Upload το zip → Extract, με
   **αντικατάσταση** των υπαρχόντων αρχείων. Μετά σβήσε το zip από τον server.
4. Άνοιξε το σαιτ και κάνε ανανέωση. Αν ο browser δείχνει την παλιά φωτογραφία, κάνε σκληρή
   ανανέωση (Cmd+Shift+R).

Το zip δεν περιέχει `.env`, οπότε το `.env` του server δεν αγγίζεται. Ούτε χρειάζεται cron για μια
αλλαγή φωτογραφίας: τα webp είναι ήδη μέσα στο zip. Τα υπόλοιπα (πρώτη εγκατάσταση, migrations) είναι
στο `docs/deployment.md`.
